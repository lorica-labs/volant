# Getting help

- Questions and ideas: [GitHub Discussions](https://github.com/lorica-labs/volant/discussions).
- Bugs and feature requests: [GitHub Issues](https://github.com/lorica-labs/volant/issues), using the templates.
- Security problems: see [SECURITY.md](SECURITY.md).

Please include your Volant version (`volant --version`), your ansible-core version if relevant, and a minimal playbook that shows the problem.
