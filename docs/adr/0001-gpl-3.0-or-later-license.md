# Use GPL-3.0-or-later for the whole repository

- Status: accepted
- Date: 2026-09-05

## Context

Volant executes unmodified Ansible modules. To do so, the controller calls ansible-core's own payload builder through an embedded Python interpreter, and the agent ships ansible-core's `module_utils` to managed hosts. ansible-core is licensed under GPL-3.0. Importing a GPL library at runtime and redistributing parts of it makes a permissive licence for Volant legally fragile.

## Decision

The whole repository is licensed GPL-3.0-or-later, the licence of Ansible and of most collections.

## Consequences

- Contributors sign off their commits under the Developer Certificate of Origin.
- Adoption is not affected: Ansible itself is a GPL command-line tool.
- When the payload builder is rewritten in Rust and the agent no longer contains ansible-core code, the agent crate may be relicensed under Apache-2.0. That will be a new decision.
