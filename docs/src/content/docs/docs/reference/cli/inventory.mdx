`volant inventory` prints an inventory as JSON, the way `ansible-inventory` does. Started under the name `ansible-inventory` (see [the shims command](/docs/reference/cli/shims/)), it behaves the same.

```
volant inventory (--list | --host HOST | --graph [GROUP]) [-i SOURCE]... [-l SUBSET] [-e VARS]... [--vars] [--output FILE] [-v]
```

Exactly one of `--list`, `--host` and `--graph` is required. `--yaml`, `--toml` and `--export` are not there yet and are unknown options.

<Option name="--list" arg="">
  Print every host with its variables, the `group_vars` and `host_vars` files and its groups' variables folded in, then the groups with their `hosts` and `children`. Keys are sorted, the indent is four spaces, and non-ASCII text is written as is. A string that is data is printed as `{"__ansible_unsafe": "..."}` and a `!vault` value as `{"__ansible_vault": "..."}`; nothing is decrypted.
</Option>

<Option name="--host" arg="HOST">
  Print the variables of one host. `HOST` is a host pattern that must match exactly one host, otherwise the command prints `You must pass a single valid host to --host parameter` and exits 5. `--limit` does not apply.
</Option>

<Option name="--graph" arg="[GROUP]">
  Print the groups as a tree: `@name:` for a group, bare names for hosts, a group's children before its hosts, each level indented by `  |`. With a group name, print only that subtree. A name that is not a group prints `Pattern must be valid group name when using --graph` and exits 5. `--limit` does not apply.
</Option>

<Option name="--vars" arg="">
  With `--graph`, add `{name = value}` lines under every host (its folded variables) and every group (its own, `group_vars` files included), sorted by name and written with Python's `str()`. `!vault` values are decrypted, so this needs the vault password, and `!unsafe` text is printed as it is. The other actions ignore `--vars`.
</Option>

<Option name="-l, --limit" arg="SUBSET">
  With `--list`, keep only the hosts matching the pattern. Groups stay, with their children. A pattern that matches nothing warns and prints an inventory with no host.
</Option>

<Option name="-e, --extra-vars" arg="VARS">
  Extra variables, added to every host and winning over every other layer.
</Option>

<Option name="--output" arg="FILE">
  Write the document to `FILE` and print nothing. The file holds what standard output would, without the last newline.
</Option>

`-i`, `-v` and the vault options work as they do for `volant playbook`. Without a selected action the command prints `No action selected, at least one of --host, --graph or --list needs to be specified.`, and with two it prints `Conflicting options used, only one of --host, --graph or --list can be used at the same time.`; both exit 5.
