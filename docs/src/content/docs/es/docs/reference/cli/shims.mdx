`volant shims` enlaza los nombres de los programas de ansible-core con `volant`, de modo que `ansible-vault` y los demás inician Volant. Nada crea estos enlaces a menos que lo ejecutes. Funciona en Linux y macOS.

```sh
volant shims install [--dir DIR] [--force] [NAME...]
volant shims remove [--dir DIR] [NAME...]
```

`NAME` es uno de `ansible`, `ansible-config`, `ansible-console`, `ansible-doc`, `ansible-galaxy`, `ansible-inventory`, `ansible-playbook`, `ansible-pull` y `ansible-vault`. Sin ninguno, el comando toma los nueve.

<Option name="--dir" arg="DIR">
  El directorio de los enlaces. Por defecto: `$VOLANT_BIN_DIR`, luego `~/.local/bin`. Un directorio que no existe es un error: `ERROR! DIR is not a directory`, código de salida 1.
</Option>

<Option name="install --force" arg="">
  Sustituye un archivo o enlace con ese nombre que no sea un enlace de Volant.
</Option>

Un shim es un enlace simbólico. Su destino es el nombre relativo `volant` cuando `DIR` contiene una entrada llamada `volant`, así que actualizar ese enlace arrastra los shims. En otro caso es la ruta absoluta del binario en ejecución.

`install` imprime una línea por nombre:

| Línea | Significado |
|---|---|
| `ansible-vault: installed` | Se creó el enlace. |
| `ansible-vault: already installed` | El enlace existe y apunta a `volant`. No cambió nada. |
| `ansible-vault: replaced` | `--force` sustituyó otro archivo o enlace. |
| `ansible-vault: not replaced, DIR/ansible-vault exists and is not a Volant link` | No se creó nada, y el código de salida es 1. |

Cuando hay otro ejecutable con ese nombre en el `PATH`, una línea que creó un enlace añade una segunda frase: `note: /usr/bin/ansible-vault is hidden by this link, DIR comes first in PATH`, o `note: /usr/bin/ansible-vault still runs first, DIR comes later in PATH`. Si `DIR` no está en el `PATH`, termina con `DIR is not in PATH`.

`remove` elimina solo los enlaces simbólicos cuyo destino es un archivo llamado `volant`, e imprime `ansible-vault: removed`, `ansible-vault: not installed` o `ansible-vault: not a Volant link, left alone`. La última hace que el código de salida sea 1.
