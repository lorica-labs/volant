## 背景

Volant 的目标是原样运行现有的 playbook。“原样”需要一个定义：ansible-core 在不同版本之间会改变行为，而 2.19 重写了模板（数据标记），带来一些有意为之的不兼容。

## 决策

Volant 复现 ansible-core 2.19 的行为。与 2.19 的差异就是 bug。golden 测试和兼容性测试框架都以该版本为比较对象。计划做一个针对 ansible-core 开发分支的夜间任务，以便在变更进入发布版本之前就看到它们，但尚未建成：目前没有任何东西在盯着那个分支。

## 后果

- 只因 2.19 中已移除的行为才能在较旧核心上运行的 playbook，不在范围之内。
- 把参照迁移到更新的核心是一个新的决策，记录在这里，并根据变化的内容提升主版本号或次版本号。
